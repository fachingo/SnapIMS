# SnapIMS v0.15.0 End-of-Batch Checklist

- [ ] Preview Item count matches physical tapes.
- [ ] NEXT photographs are not attached to Items.
- [ ] Location is correct or intentionally unassigned.
- [ ] Recognition failures/blocks were reviewed.
- [ ] Titles, prices, tags, descriptions, quantities, conditions, Rare, and Review flags are correct.
- [ ] CSV row count and Item IDs were verified when CSV was used.
- [ ] Publish validation shows PASSED and zero blockers.
- [ ] Shopify simulation shows intended Items ready.
- [ ] Draft job completed with no unexplained failures or duplicates.
- [ ] Drafts were reviewed in Shopify when required.
- [ ] Live publishing used exact `SUBMIT`, or direct live used exact `SUBMIT LIVE` deliberately.
- [ ] Shopify Product/Variant/Inventory GIDs and final status are visible in SnapIMS.
- [ ] Failed Items were retried or documented.
- [ ] Publish history and Diagnostics were reviewed.
- [ ] SnapIMS was stopped before offline backup.
