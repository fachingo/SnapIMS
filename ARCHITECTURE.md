# SnapIMS v0.13.2 Architecture

- FastAPI web application and CLI.
- SQLite inventory database, current schema 15.
- Durable folder/photo Import cache and background jobs.
- Immutable Batch and Item identities.
- Preserved original photographs plus derived previews/recognition images.
- Server-side bounded Batch Editor and Publish paging.
- Controlled Tags, audit history, checkpoints, CSV round trip, Recognition, Review, and guarded Shopify workflow.
- Pinned per-user launcher and service prevent source/schema version mismatch.
